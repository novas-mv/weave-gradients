Weave Gradients

Version 1.2.0 · 2026-10-11 · What's new

Aurora-style gradient weaves: soft colour blooms and fabric-like folds. Make them in your browser, or right inside Figma, at print resolution.

Open the studio Get the Figma plugin

The studio

A web page. Nothing to install. Pick a preset, tune it, download a PNG up to print size.

The Figma plugin

The same panel inside Figma. Insert weaves as editable layers you can reopen and update later.

Using the studio

  1. Open the studio and click a preset.
  2. Gradient: click the bar to add a colour stop, drag to move it, Backspace to remove.
  3. Generative weave makes random folds — press Shuffle for a new one. Compose layers lets you place each ribbon and colour bloom yourself; drag the dots on the preview.
  4. Pick a size and resolution under Output, then Download image.

The controls that matter most

Edge sharpnessSoft aurora at low values, crisp silk folds at high values
Glow · AuraHow much the light colours spread and bloom
Weave rotationTurns the folds. Gradient angle turns the colours underneath, separately
Fold shadow · RollOn a ribbon layer: the shadow tucked under the fold, and how rounded the fold looks

Installing the Figma plugin

  1. Download the plugin (v1.2.0) and unzip it.
  2. Move the folder somewhere permanent — Documents, not Downloads. Figma reads these files every time, so if the folder moves the plugin stops working.
  3. In Figma: Plugins → Development → Import plugin from manifest…
  4. Choose plugin/manifest.json inside that folder.

It now lives under Plugins → Development → Weave Gradients. You only do this once.

Using it

  1. Run the plugin and make a weave the same way as in the studio.
  2. Choose a size — or select a frame first and pick Selection to fill it.
  3. Pick Editable or Flattened, then Insert in Figma.

Editable vs flattened

EditableThe layer remembers its settings. Select it (or click Edit weave in Figma's right panel), change anything, press Update layer
FlattenedA plain image with no link back to the plugin
Insert newStops editing the selected layer so you can make a fresh one

Printing big

Use Download rather than inserting into Figma. Pick the paper size and 300 dpi for A4–A1, 150 dpi for A0 and larger — smooth gradients print cleanly at 150. The PNG carries its DPI, so it opens at the right physical size. One file tops out around 240 megapixels.

Inside Figma, anything over 4096 px is split into seamless tiles, because that's Figma's image limit.
